# Contributing

Thank you for helping improve this reference starter. By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Before opening a change

- Search existing issues and pull requests.
- For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
- Keep changes scoped and explain affected interfaces, trust boundaries, and residual risk.
- Do not include credentials, personal data, proprietary prompts/data, dependency directories, or unrelated formatting churn.

## Development

Use the runtime and exact dependency commands documented in this repository's README. Add or update tests for behavior changes, run the relevant static checks, and keep lockfiles synchronized with intentional dependency changes.

## Pull requests

Describe what changed, why, security impact, validation commands, compatibility considerations, and remaining limitations. Passing CI is necessary but does not establish production readiness, security certification, or endorsement.

Contributions are submitted under the repository's Apache License 2.0 unless explicitly stated otherwise.
