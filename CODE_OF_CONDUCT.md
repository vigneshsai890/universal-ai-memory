# Code of Conduct

We are committed to a respectful, inclusive, and harassment-free community. Be constructive, assume good faith, respect privacy, and avoid personal attacks, discrimination, threats, or unwanted contact.

Project maintainers may remove content or restrict participation for behavior that violates these standards. If GitHub Private Reporting is enabled, use it for sensitive conduct reports; otherwise contact the repository owner privately through a verified channel. Do not publish personal information or sensitive allegations in public issues.

This policy is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
